# Security Awareness Program Charter

## Program Name

Organizational Security Awareness Program

## Program Purpose

The purpose of this program is to improve secure behaviours across the organization by providing practical, role-based, and continuous security awareness training.

## Program Objectives

The objectives are to:

1. Improve employee understanding of cyber threats and safe working practices.
2. Reduce phishing, social engineering, credential compromise, data leakage, and policy violations.
3. Build a strong reporting culture.
4. Support compliance with information security, privacy, and acceptable use requirements.
5. Equip high-risk teams with role-specific security guidance.
6. Provide management with measurable indicators of awareness maturity.

## Scope

This program applies to:

- Employees
- Contractors
- Temporary workers
- Privileged users
- Executives
- High-risk business functions
- Third parties where relevant

## Program Ownership

| Role | Responsibility |
|---|---|
| Executive Sponsor | Provides leadership support and visibility. |
| Security Team | Owns program delivery, content, metrics, and improvement actions. |
| GRC / Compliance Team | Aligns the program with policy, risk, audit, and regulatory requirements. |
| HR / People Team | Supports onboarding, training assignment, and training records. |
| Department Managers | Reinforce participation and role-specific responsibilities. |
| Employees and Contractors | Complete training and report suspicious activity. |

## Review Frequency

The program should be reviewed quarterly and refreshed annually.
