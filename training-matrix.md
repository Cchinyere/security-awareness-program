# Security Awareness Training Matrix

## Purpose

This training matrix defines the recommended security awareness training for different user groups across an organization.

The purpose of the matrix is to ensure that each audience receives security awareness training that is relevant to their role, risk exposure, and responsibilities.

Security awareness should not be the same for everyone. While all staff need core security training, high-risk teams such as finance, HR, executives, IT administrators, developers, and customer-facing teams require additional role-based training.

## Training Objectives

The objectives of this training matrix are to:

1. Define mandatory security awareness training for all staff.
2. Identify role-based training requirements for high-risk groups.
3. Support onboarding and annual refresher training.
4. Address AI-era threats such as deepfakes, voice cloning, AI-generated phishing, and unsafe use of AI tools.
5. Provide evidence for audit, compliance, and governance reviews.
6. Support continuous improvement of security behaviours across the organization.

## Core Training for All Staff

All staff should complete baseline security awareness training.

## Required Topics

Core security awareness should include:

- Why cybersecurity matters to the organization
- Acceptable use of systems and data
- Phishing and social engineering
- Passwords and multi-factor authentication
- Data protection and privacy
- Secure use of email and collaboration tools
- Secure remote and hybrid working
- Device security
- Ransomware awareness
- Incident and suspicious activity reporting
- Safe use of approved AI tools
- What not to share with public or unapproved AI tools

## Expected Behaviours

All staff should be able to:

1. Recognize common signs of phishing and social engineering.
2. Report suspicious emails, messages, calls, or system activity.
3. Use strong authentication and protect credentials.
4. Handle sensitive information securely.
5. Use approved tools and follow acceptable use requirements.
6. Verify unusual requests through trusted channels.
7. Avoid entering confidential or personal data into unapproved AI tools.
8. Report mistakes quickly without fear of blame.

## New Starter Security Onboarding

New starters should receive security awareness training early in their employment.
