# Monthly Security Awareness Campaign Calendar

Security awareness should be continuous, practical, and linked to real workplace risks.

| Month | Theme | Example Activities |
|---|---|---|
| January | Cybersecurity Basics | Security checklist, password review, MFA reminder |
| February | Phishing and Social Engineering | Suspicious email examples, reporting reminder |
| March | Data Protection and Privacy | Safe data handling, secure sharing guidance |
| April | Passwords and MFA | Password manager guidance, MFA fatigue awareness |
| May | Secure Remote Working | Home Wi-Fi, VPN, device locking |
| June | Ransomware Awareness | Suspicious attachments, backup awareness |
| July | Travel and Mobile Security | Public Wi-Fi, lost device reporting |
| August | Cloud and Collaboration Tools | Safe file sharing, link permissions |
| September | Insider Risk and Workplace Security | Access misuse, reporting concerns |
| October | Cybersecurity Awareness Month | Organization-wide campaign, quizzes, leadership message |
| November | Fraud and Payment Security | Invoice fraud, supplier impersonation |
| December | Year-End Security Review | Holiday scams, lessons learned, secure closure |

## Campaign Template

Each monthly campaign should include:

- Campaign theme
- Target audience
- Key message
- Delivery channels
- Call to action
- Supporting materials
- Success measures
- Owner
- Launch date
